# Kerolos Habib Portfolio

A responsive bilingual (English/Arabic) portfolio built with plain HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Internet access is only needed for the optional Google Fonts.

## Included features
- Responsive desktop, tablet, and mobile layouts
- English/Arabic language switcher with automatic LTR/RTL direction
- Light/dark theme toggle (preference saved in the browser)
- Mobile navigation menu
- Smooth scrolling and reveal-on-scroll animations
- Skills, training, education, experience, projects, and contact sections

## Before publishing
- Replace generic project GitHub links with direct repository links for each project.
- Add a CV PDF and link it from the hero if you want a downloadable CV button.
- Add a profile photo if desired. The hero currently uses a CSS code illustration so it does not pretend to be your portrait.
- Double-check personal details, language proficiency, and training status before sharing publicly.

## Publish it for free
You can upload the contents of this folder to a GitHub repository and enable GitHub Pages in the repository's Settings → Pages.
